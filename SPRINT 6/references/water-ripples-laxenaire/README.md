# WebGL water ripples

A Pen created on CodePen.

Original URL: [https://codepen.io/martinlaxenaire/pen/OJVKVYa](https://codepen.io/martinlaxenaire/pen/OJVKVYa).

Water ripples using FBOs swapping (ping pong shading).

This example is a port of @shubniggurath's pen https://codepen.io/shubniggurath/pen/OEeMOd from three.js to curtains.js
 Most of the fragment shaders are borrowed from that pen. However I tweaked them a little and removed some stuff originally done in here (env map, heavy blur, noise...)
Thanks to @edankwan for his precious help.
