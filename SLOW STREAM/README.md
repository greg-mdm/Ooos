# Slow Stream

Source library for **slowstream.ca**, the Slow Stream Wix site (Wix Studio, site ID `8dfcac3a-32e5-4f70-981b-9c7c64af05ae`). Opened 2026-10-26.

Nothing in this folder is served by ooos.ca; only `public/` is. Files here are the masters. Web-ready copies are cut from them and uploaded to the Wix site's Media Manager.

## The site

A simple two-page layout, based on the Wix template Greg chose (https://www.wix.com/website-template/view/html/3545):

1. **Featured videos**: the Slow Stream shorts.
2. **Store**: the shop, with a page per product (first product: Shadow | Framed Art Print).

Contact: relax@slowstream.ca

## Folders

- `brand/`: the logo and any other brand marks, full size (PNG with transparency preferred).
- `videos/`: the video shorts, as cut (MP4 preferred).

## Notes

- GitHub refuses single files over 100 MB. Keep each video under that, or split a long one.
- Keep the original file names on upload; web copies get their own names when they are cut.
